// After It Ships

A research scientist
that never sleeps.

A model trained on a fixed, hand-labeled dataset starts drifting from field conditions the day it ships, and the fix is another labeling round. Our deployed models feed the same self-labeling loop they were built with, so accuracy improves after deployment rather than degrading.

Self-improvement isn't a script, it's an autonomous agent that reads every model result and diagnoses the root cause: a model problem, or a data problem? If it's the model, the agent tunes the training configuration and proposes an updated model. If it's the data, it triggers the auto-label flywheel to harvest and self-verify new training examples. The monitoring, the diagnosis and the overnight experiments run on-premises with no ML engineer of yours in the loop. Nothing deploys itself: a human approves every promotion. // Roadmap: having the agent read and apply methods from current literature is a roadmap item, not a shipped capability.

what off-the-shelf actually scores

The things that did not work

Open-vocabulary detectors scored 1 to 8 percent on this imagery. Three verifier approaches failed, each in a different way. Full fine-tuning collapsed three separate times, at three different class counts, before we retired it. Every one of those is in our research record with the run that produced it.

0
synthetic-data wins claimed

The experiment we lost

Synthetic data augmentation was run head to head against real photographs and lost. It is not claimed as a win anywhere in this product, on this page, or in our deck. It was the most carefully engineered pipeline we had built at the time, and it still hurt training.

6/12
forecasts falsified, on record

We sell measurement, not prediction

Four separate up-front difficulty predictors failed out of sample, which is why we will not forecast how well your assets will work and will instead measure it on your imagery. Twelve pre-registered forecasts are on record: six held, six were falsified. Each was written down and committed before the result existed, which is the only reason we can tell you which half is which.

0.87
promised · 0.43–0.73 delivered

Known defect, stated

The 40-frame calibration does not transfer to the full archive. It reports roughly 0.87 precision for every asset while the truth spans 0.43 to 0.73, and it cannot even rank which asset is worst. That means a customer running the loop today cannot tell from the system alone how clean its auto-labels are. The fix is under test and ships before we call onboarding autonomous. We would rather you read this here than discover it yourself.
